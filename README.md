# aNewbie Wiki

Documentation for [aNewbie](https://www.spigotmc.org/resources/120435/), a Minecraft plugin that protects new
players for a limited time, or until they reach a block-based limit.

## → [Read the documentation in the Wiki](https://github.com/mustiffy/aNewbie-Wiki/wiki)

The pages live in this repository's wiki, not in the repository itself. Everything is there:

| [Protection Modes](https://github.com/mustiffy/aNewbie-Wiki/wiki/Protection-Modes) | Time-based and block-based behavior |
| [Restrictions](https://github.com/mustiffy/aNewbie-Wiki/wiki/Restrictions) | Damage, explosions, worlds, regions, vehicles |

## Editing

The wiki is its own git repository. Clone it to edit the pages offline:

```bash
git clone https://github.com/mustiffy/aNewbie-Wiki.wiki.git
```

Pages are flat Markdown files at the root. Link to another page by name, without the extension, for
example `[Storage](Storage)`. `_Sidebar.md` is the navigation shown beside every page.

## Support

When asking for help, include the aNewbie version, server software and version, Java version, storage
type, the relevant config section, and the full console error if one was printed.
